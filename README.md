# Snake Game (Jogo da Cobrinha)

Projeto desenvolvido para a disciplina de Processamento Digital de Imagens, como atividade prática de aplicação dos conceitos vistos em aula utilizando Python e a biblioteca Pygame.

## Como executar

### Pré-requisitos
- Python 3 instalado
- Biblioteca Pygame instalada

Para instalar o Pygame, execute:
```
pip install pygame
```

### Rodando o jogo
Com o Python e o Pygame instalados, execute o arquivo principal:
```
python snakeGame.py
```

## Como jogar
- Use as setas do teclado (↑ ↓ ← →) para controlar a direção da cobra.
- O objetivo é comer os alimentos (quadrados vermelhos) para crescer e aumentar a pontuação.
- O jogo termina se a cobra bater na borda da tela ou em seu próprio corpo.
- Após o Game Over, pressione ENTER para reiniciar a partida ou ESC para fechar o jogo.
